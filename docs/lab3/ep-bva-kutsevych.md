# EP та BVA — Куцевич

## inputText(text)

### EP
- коректний рядок
- не рядок
- порожній рядок / лише пробіли
- занадто довгий рядок

### BVA
- довжина 0
- довжина 1
- довжина 500
- довжина 501

## formatPunctuation(text)

### EP
- текст без розділових знаків
- текст з крапкою
- текст із знаком оклику
- текст із знаком питання
- текст із комою
- текст із зайвими пробілами

### BVA
- не застосовується явно, основний акцент на EP

## generateMessage(text, tone)

### EP
- коректний текст + formal
- коректний текст + friendly
- коректний текст + professional
- некоректний текст

### BVA
- текст довжини 1
- текст довжини 500
- текст довжини 501
